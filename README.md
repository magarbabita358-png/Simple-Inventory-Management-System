# Simple Inventory Management System

A C# Windows Forms application for retail product management and stock monitoring, built for ITS203 Object-Oriented Design and Programming (Milestone 2).

## Technologies
- C# / .NET 8 Windows Forms
- Visual Studio
- JSON storage with `System.Text.Json`

## Features (Milestone 2)
- Product data model with automatic low-stock status calculation
- In-memory inventory management with duplicate ID validation and search
- JSON persistence (`Data/products.json`)
- Clean Windows Forms interface with DataGridView and selection auto-fill
